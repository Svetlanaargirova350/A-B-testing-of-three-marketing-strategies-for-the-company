# A-B-testing-of-three-marketing-strategies-for-the-company
A/B тестирование трех маркетинговых стратегий для компании (137 ресторанов, 4 недели, 548 наблюдений). Данные использовались с Kaggle. В исследовании использовались следующие методы: критерий хи-квадрат, критерии Левена и Шапиро — Уилка, критерий Краскела — Уоллиса, критерий Манна — Уитни с поправкой Бонферрони, бутстрап-доверительные интервалы
